# WishingASR v70.0 — Ultra-Luxury Editorial Redesign & AdSense Quality Release

WishingASR is a static HTML/CSS/JavaScript platform for thoughtful greetings, personalized greeting cards, and occasion-based creative tools in English, Hindi, and Hinglish.

## Local preview

- Windows: double-click `START_LOCAL_PREVIEW.bat` (or run `python run_local_preview.py`).
- Open the localhost URL printed in the command window.

## v70.0 Upgrades

- **Handcrafted-First Wish Engine (`app.js` & `tools.js`):** Uses curated English, Devanagari Hindi, and Hinglish greetings first, with non-repeating variations on regeneration.
- **Interactive 45-Formation Drone Light Show (`index.html`, `app.js`, `styles.css`):** Quick-switch occasion pills and a "Next show ↻" cycler directly below the sky display stage, plus constellation filaments and adaptive device performance caps.
- **20 Unique Greeting Card Themes (`app.js` & `styles.css`):** Every card design renders its own bespoke canvas frame geometry, corner filigree, and matching live preview surface.
- **Viral Quote Search & "Customize on Card ↗" Deep-Links (`quotes.html`, `national-days.html`, `growth.js`, and all 19 guides):** Filter by keyword or language, copy in one tap, share on WhatsApp, or launch the Greeting Card Studio with that wish pre-filled.
- **Google AdSense & SEO Readiness:** Occasion-specific `<h2>` headings and cultural etiquette sections across all 20 guides, occasion-matched page palettes (`data-theme="..."`), `FAQPage` JSON-LD across all FAQ guides, mobile navigation on all pages, bespoke 1200×630 luxury Open Graph banner (`assets/social-preview.jpg`), ad-free trust/utility pages (`about.html`, `contact.html`, `privacy.html`, `terms.html`, `aa-group.html`), and `v=70.0` cache-busted asset references.

## Deployment to Vercel

1. Extract this ZIP.
2. Upload **all files and folders inside `wishingasr_work/`** (`index.html`, `app.js`, `styles.css`, `assets/`, etc.) directly into the root of your Vercel-connected GitHub repository (replacing the older files).
3. Wait for Vercel to finish building and verify `https://wishingasr.vercel.app/` with a hard refresh (`Ctrl + Shift + R`).
