# WishingASR v66.0 — Editorial Quality & Performance Polish

## What changed

- Rewrote repeated guidance blocks across 19 occasion and language collection pages with page-specific advice for birthdays, weddings, anniversaries, festivals, morning/evening messages, love notes, WhatsApp captions, and English/Hindi/Hinglish writing.
- Reworked the page-specific card-creation guidance so each guide explains a relevant composition, readability or sharing consideration rather than repeating the same generic call to action.
- Improved the language-specific collections with appropriate English, Hindi and Roman-Hinglish guidance.
- Added a restrained editorial reading-surface refinement for guide intros, keyboard focus visibility and reduced-motion preferences.
- Updated versioned CSS/JS asset references to `66.0` so the browser does not retain the prior immutable stylesheet cache.
- Updated sitemap `lastmod` values for the revised editorial pages.

## Preserved

All existing 20 card designs, Hindi/English/Hinglish options, browser-based card creation and photo processing, PNG export formats, saved wishes, invitation maker, planner, calendar, tools, 45 occasion drone formations, backup/restore, Vercel routes, legal pages, publisher ID and authorized `ads.txt` entry remain in place.

## AdSense-related work

The primary diagnosed quality opportunity was repetitive, generic content across multiple guide pages. The release makes those sections more specific and more useful. It does not guarantee AdSense approval; Google's review considers the complete live site, content, navigation, user experience and policy compliance.

## Deployment

This ZIP is a source release and does not deploy itself. Upload the contents of `wishingasr_work` to the existing Vercel project and redeploy. The live site will not change until deployment completes. After deployment, verify key routes, `robots.txt`, `sitemap.xml`, canonical URLs and `https://wishingasr.vercel.app/ads.txt` in a browser, then request a new AdSense review only after the live site is checked.
